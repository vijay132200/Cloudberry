ISSUE 1 — PHYSICIAN CANNOT COMMENT ON DIET PLAN PDF

===================================================



Current Issue:



Physicians can view the Diet Plan section but cannot properly comment on uploaded Diet Plan PDFs.



Required Fix:



* Enable physician commenting on Diet Plan PDFs.

* Comments must save successfully.

* Comments must persist in the database.

* Comments must remain visible after refresh and restart.

* Comments should display:



  * Author

  * Role

  * Timestamp

  * Last Modified Timestamp



Support:



* Add Comment

* Edit Comment

* View Comment History



Visibility:



* Physician Portal

* Operations Portal

* Patient Portal (if visibility settings allow)



==================================================

ISSUE 2 — PATIENT CANNOT VIEW DIET PLAN PDF

===========================================



Current Issue:



Diet Plan PDFs are uploaded successfully but patients cannot view or download them.



Audit and trace:



* PDF upload flow

* Database storage

* File reference storage

* Retrieval APIs

* Patient Portal rendering logic

* Permissions layer



Required Fix:



When a Diet Plan PDF exists:



Patient must be able to:



* View PDF

* Download PDF

* View current version

* View historical versions (if available)



Replace any incorrect:



"No PDF attached to this plan"



messages when a valid file exists.



Verify functionality across:



* Patient Portal

* Physician Portal

* Operations Portal
